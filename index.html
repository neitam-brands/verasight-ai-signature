How to install your signature:

Gmail

  1. Click "Copy Signature" above.
  2. In Gmail, click the Settings (gear) icon > "See all settings".
  3. Scroll down to the "Signature" section and click "Create new".
  4. Paste (Ctrl+V / Cmd+V) into the text box.
  5. Save changes at the bottom of the page.

Apple Mail (Mac)

  1. Click "Copy Signature" above.
  2. Open Mail > Preferences/Settings > Signatures.
  3. Create a new signature (+).
  4. Uncheck "Always match my default message font".
  5. Paste (Cmd+V) into the box (it might look slightly off here, but sends perfectly).

Outlook

  1. Click "Copy Signature" above.
  2. In Outlook, go to File > Options > Mail > Signatures.
  3. Click "New".
  4. Paste (Ctrl+V / Cmd+V) into the edit area.
  5. If a paste options icon appears, choose "Keep Source Formatting".
